# CAPACITI implementation summary

The Youth Portal was upgraded from a browser-local static prototype into a server-backed Youth Service Request Management System while retaining the original Youth Portal visual identity, opportunity discovery, career resources, profile experience, and responsive styles.

The implementation now has two separate workspaces. The User Dashboard is limited to the authenticated user’s own requests, counts, submissions, references, filters, profile fields, details, replies, and status history. The Admin Dashboard is limited to authorized administrators and provides all-user request management, database-backed statistics, search/sort/date/category/status/priority filters, replies, persisted status changes, internal-note privacy, assignment, category administration, and role management. Staff keep a separate assigned-workspace role.

The relational model includes users/profiles, roles, permissions, sessions, request categories, service requests with unique references, request updates/status history, and request messages with sender, timestamp, and internal visibility. Passwords are bcrypt-hashed; sessions are random server-side tokens stored as hashes; role and ownership checks run in backend middleware and parameterized SQL. Wrong-dashboard access is denied and redirected by the backend rather than merely hidden in navigation.

The project includes additive migrations, a forgot-password entry point with explicit email-provider setup guidance, validation, safe errors, escaped message rendering, secure cookies, CSRF checks, strict CSP-compatible external scripts, invitation-gated administrator registration, database-backed opportunity management, direct administrator status controls, Docker deployment configuration, route manifest, setup guidance, and test evidence. The expanded live acceptance suite passed 48 assertions covering authentication modes, role separation, invitation-gated registration, request references, ownership isolation, user/admin replies, internal-note privacy, direct status synchronization, opportunity add/delete synchronization, assignment, role management, and persistence. An authenticated Sandbox Preview pass confirmed both dashboards initialize and render live data and controls.
